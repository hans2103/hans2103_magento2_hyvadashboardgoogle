# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

### Added

- Widget "Google: Top search queries" (Search Console).
- Widget "Google: Search performance" (Search Console line chart).
- Widget "GA4 vs Magento: e-commerce check" with a per-order list of orders missing in GA4.
- Encrypted service account configuration, per-store-view GA4 property, hostname filter and Search Console property.
- Response, token and error caching to protect Google API quotas.
- CLI command `hans2103:dashboard-google:test`.
- English and Dutch translations.
